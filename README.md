# Bases de Datos · laboratorio SQL y recursos

Sitio estático: laboratorio SQL en el navegador (sql.js, SQLite compilado a WebAssembly) con la base de datos ficticia TiendaTech, figuras, ejemplos por unidad y una batería de 20 ejercicios organizados por UT y dificultad. La batería cubre los RA1-RA7 y todos sus criterios de evaluación; sus enunciados están en `ejercicios/`.

Los solucionarios y las pruebas no se publican. Todos los datos de las prácticas son ficticios.

Para regenerar las páginas de ejercicios desde su fuente JSON: `python3 ejercicios/build.py`.
