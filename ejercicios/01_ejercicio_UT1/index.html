Del archivo a la base de datos

Nivel 1 de 2 · Almacenamiento de la información y SGBD

Batería de ejercicios › UT1 › 01_ejercicio_UT1
Resultado de aprendizaje: RA1. Reconoce los elementos de las bases de datos analizando sus funciones y valorando la utilidad de los sistemas gestores.
Criterios trabajados: a), b), c), d), e), f)

Situación

Una pequeña tienda guarda clientes, productos y pedidos en hojas de cálculo independientes; cada vendedor mantiene además una lista local de contactos.

Enunciado

  1. Clasifica los sistemas lógicos de almacenamiento que aparecen y compara sus características para este caso.
  2. Propón qué información debería gestionarse con una base de datos y qué podría seguir en ficheros; justifica la elección.
  3. Identifica el modelo de datos y la ubicación de la información que mejor encajan. Compara al menos dos alternativas.
  4. Explica qué es un SGBD y relaciona sus funciones y componentes con dos problemas concretos del escenario.

Entrega

Una tabla comparativa de las alternativas y una recomendación razonada de una página. Incluye un pequeño esquema de componentes del SGBD.

Ampliación (opcional, no evaluable)

  • Prepara un entorno de trabajo reproducible: levanta MySQL 8.4 con el `docker-compose.yml` de Material, conéctate con DataGrip (host `localhost`, puerto 3306) y ejecuta `SELECT VERSION();`. Explica qué datos se pierden con `docker compose down -v` y por qué.
