Diseño de una solución distribuida y responsable

Nivel 2 de 2 · Almacenamiento de la información y SGBD

Batería de ejercicios › UT1 › 02_ejercicio_UT1
Resultado de aprendizaje: RA1. Reconoce los elementos de las bases de datos analizando sus funciones y valorando la utilidad de los sistemas gestores.
Criterios trabajados: c), d), e), f), g), h), i), j)

Situación

TiendaTech tiene un almacén en Totana y dos puntos de venta. Necesita consultar existencias, conservar pedidos y analizar ventas sin exponer datos personales innecesarios.

Enunciado

  1. Compara una base de datos centralizada con una distribuida y recomienda una para la empresa, indicando ventajas, riesgos y necesidades de disponibilidad.
  2. Diseña una propuesta de fragmentación horizontal o vertical para productos y pedidos. Indica qué fragmentos se ubicarían en cada sede y cómo se reconstruiría la información.
  3. Clasifica tres SGBD apropiados para alternativas distintas (relacional, documental u otra) e indica sus elementos y funciones relevantes.
  4. Enumera medidas de protección de datos personales aplicables: finalidad, minimización, control de acceso, conservación y seguridad. No uses datos reales.
  5. Propón dos preguntas de análisis para un cuadro de mando y explica cuándo el volumen o la variedad justificarían hablar de Big Data.

Entrega

Diagrama de distribución, tabla de fragmentos y breve informe de decisión que incluya privacidad, Big Data e inteligencia de negocios.
