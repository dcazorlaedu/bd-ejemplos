Modelo E-R para una cafetería

Nivel 1 de 3 · Diseño lógico: E-R y normalización

Batería de ejercicios › UT2 › 03_ejercicio_UT2
Resultado de aprendizaje: RA6. Diseña modelos relacionales normalizados interpretando diagramas entidad/relación.
Criterios trabajados: a), b), c), d), e)

Situación

Una cafetería quiere registrar clientes, mesas, reservas, productos de carta y pedidos. Cada reserva pertenece a un cliente y una mesa; un pedido puede incluir varios productos y cada producto puede aparecer en muchos pedidos.

Enunciado

  1. Identifica entidades, atributos, identificadores y relaciones. Incluye los datos mínimos para resolver el escenario.
  2. Indica cardinalidad y participación de cada relación; justifica las decisiones que no se deducen literalmente del enunciado.
  3. Dibuja el diagrama E-R con una herramienta gráfica y añade una leyenda de símbolos.
  4. Convierte el diagrama en una primera lista de tablas, marcando las claves primarias y ajenas.

Entrega

Diagrama E-R legible, lista de tablas y una breve explicación de dos decisiones de modelado.
