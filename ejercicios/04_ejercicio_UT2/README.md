# 04_ejercicio_UT2 · Del E-R al modelo relacional

**UT2 · RA6 · Nivel 2**
Diseño lógico: E-R y normalización

**Resultado de aprendizaje:** Diseña modelos relacionales normalizados interpretando diagramas entidad/relación.
**Criterios trabajados:** a), b), c), d), e), f), h)

## Situación

Una academia programa cursos con varias ediciones. Cada edición tiene docentes y alumnado; una persona puede impartir varias ediciones y matricularse en varias.

## Enunciado

1. Completa un diagrama E-R con las entidades Persona, Curso, Edición y Matrícula, más la relación entre docente y edición.
2. Transforma el modelo en tablas relacionales. Resuelve las relaciones N:M mediante tablas intermedias y especifica tipos de clave.
3. Define reglas de integridad para fechas, plazas, nota final y estados de matrícula. Clasifica cuáles se pueden expresar con PK, FK, UNIQUE, NOT NULL o CHECK.
4. Documenta dos restricciones semánticas que necesiten lógica adicional (por ejemplo, que la fecha de fin sea posterior al inicio).

## Entrega

Diagrama E-R, esquema relacional con claves y restricciones, y una tabla de reglas indicando cómo se implementa cada una.

## Material

Utiliza únicamente datos inventados y documenta tus supuestos.
