# 05_ejercicio_UT2 · Normalización del registro de pedidos

**UT2 · RA6 · Nivel 3**
Diseño lógico: E-R y normalización

**Resultado de aprendizaje:** Diseña modelos relacionales normalizados interpretando diagramas entidad/relación.
**Criterios trabajados:** b), c), d), e), f), g), h)

## Situación

Se parte de una hoja única con: pedido, fecha, cliente, email, ciudad, producto, categoría, proveedor, teléfono del proveedor, cantidad y precio de venta. Un pedido puede incluir varios productos.

## Enunciado

1. Propón una clave candidata y escribe las dependencias funcionales que asumirías. Explicita cualquier supuesto.
2. Separa los datos repetidos y lleva la estructura a 1FN, 2FN y 3FN, mostrando cada descomposición.
3. Comprueba si alguna relación requiere BCNF y justifica el resultado con sus dependencias.
4. Para cada tabla final, indica atributos, clave primaria, claves ajenas y restricciones de integridad; comprueba que la descomposición no pierde información.

## Entrega

Desarrollo paso a paso de las formas normales y esquema relacional final. Incluye las dependencias funcionales y los supuestos.

## Material

Utiliza únicamente datos inventados y documenta tus supuestos.
