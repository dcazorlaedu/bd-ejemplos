Construye el esquema de una biblioteca

Nivel 1 de 3 · Creación de bases de datos relacionales

Batería de ejercicios › UT3 › 06_ejercicio_UT3
Resultado de aprendizaje: RA2. Crea bases de datos definiendo su estructura y las características de sus elementos según el modelo relacional.
Criterios trabajados: a), b), c), d), e), h)

Situación

Una biblioteca necesita gestionar libros, ejemplares, personas usuarias y préstamos. Un libro puede tener varios ejemplares; un ejemplar puede aparecer en muchos préstamos a lo largo del tiempo.

Enunciado

  1. Crea la base de datos y las tablas Libro, Ejemplar, Usuario y Prestamo con tipos de datos adecuados; utiliza una herramienta gráfica (por ejemplo, DataGrip) y conserva el DDL generado o escrito.
  2. Define claves primarias y ajenas, campos obligatorios y restricciones para evitar identificadores duplicados y fechas incoherentes.
  3. Añade un índice justificado para una búsqueda frecuente y documenta el formato de almacenamiento elegido.
  4. Inserta unos pocos registros de prueba y demuestra que una restricción impide una operación inválida.

Entrega

Guion DDL ejecutable en MySQL 8.4, diagrama del esquema y evidencia de una prueba válida y otra rechazada por una restricción.

Ampliación (opcional, no evaluable)

  • Elige y justifica el juego de caracteres y el cotejamiento de la base de datos (`utf8mb4`; ¿`_ai_ci`, `_as_cs` o el español `es_0900_ai_ci`?). Comprueba con tildes, «ñ» y emojis cómo afecta a las comparaciones, a `ORDER BY` y a una restricción `UNIQUE`.

Material y herramientas

Descargar esquema y datos ficticios de TiendaTech (MySQL 8.4). Trabaja en una base de datos de pruebas, no en una instancia compartida. También puedes abrir el laboratorio SQL del sitio para las consultas compatibles con SQLite.
