# 11_ejercicio_UT4 · Informe de ventas por ciudad

**UT4 · RA3 · Nivel 3**
Realización de consultas

**Resultado de aprendizaje:** Consulta la información almacenada en una base de datos empleando asistentes, herramientas gráficas y el lenguaje de manipulación de datos.
**Criterios trabajados:** e), g)

## Situación

El área comercial prepara un informe mensual basado en pedidos, clientes y líneas de pedido.

## Enunciado

1. Calcula el número de pedidos y el importe total por ciudad, agrupando los registros y usando HAVING para mostrar solo ciudades que superen el umbral que elijas.
2. Obtén el producto más vendido por unidades y explica cómo se resuelven empates.
3. Combina en una salida clientes con pedidos entregados y clientes que aún no tienen pedidos, identificando el origen de cada fila.
4. Añade una consulta con UNION que combine dos grupos de productos con columnas compatibles y elimine duplicados.

## Entrega

Guion con consultas resumen y de selección múltiple, más una explicación de agrupación, HAVING y UNION.
