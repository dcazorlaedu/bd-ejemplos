Mantenimiento seguro del catálogo

Nivel 1 de 3 · Tratamiento de datos

Batería de ejercicios › UT5 › 13_ejercicio_UT5
Resultado de aprendizaje: RA4. Modifica la información almacenada en la base de datos utilizando asistentes, herramientas gráficas y el lenguaje de manipulación de datos.
Criterios trabajados: a), b), h)

Situación

El almacén debe dar de alta un proveedor y varios productos, actualizar existencias y retirar un producto descatalogado.

Enunciado

  1. Identifica la herramienta y las sentencias DML adecuadas; escribe operaciones INSERT para el proveedor y productos, respetando claves ajenas y valores obligatorios.
  2. Actualiza el stock de los productos afectados con una condición que identifique de forma inequívoca las filas.
  3. Elimina un producto de prueba y analiza qué ocurre si sigue referenciado por una línea de pedido.
  4. Incluye consultas de comprobación antes y después, y explica qué restricciones protegen la integridad.

Entrega

Guion SQL reproducible sobre una copia de pruebas, con comentarios, comprobaciones y un caso de error controlado.

Material y herramientas

Descargar esquema y datos ficticios de TiendaTech (MySQL 8.4). Trabaja en una base de datos de pruebas, no en una instancia compartida. También puedes abrir el laboratorio SQL del sitio para las consultas compatibles con SQLite.
