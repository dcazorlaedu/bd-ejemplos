# 16_ejercicio_UT6 · Automatiza un informe de stock

**UT6 · RA5 · Nivel 1**
Programación de bases de datos

**Resultado de aprendizaje:** Desarrolla procedimientos almacenados evaluando y utilizando las sentencias del lenguaje incorporado en el sistema gestor de bases de datos.
**Criterios trabajados:** a), b), c), d), e)

## Situación

El equipo de almacén solicita un informe repetible con productos bajo mínimos y el número total de referencias afectadas.

## Enunciado

1. Compara tres formas de automatizar la tarea: guion SQL ejecutado manualmente, procedimiento almacenado y evento programado.
2. Identifica una herramienta para editar y ejecutar el guion; describe cómo guardar el resultado de forma reproducible.
3. Escribe un guion que use funciones del sistema gestor para calcular el momento de ejecución y filtrar productos bajo mínimos.
4. Añade comentarios, una variable de usuario o local y una comprobación que permita repetir el informe sin modificar los datos.

## Entrega

Guion MySQL ejecutable, salida de ejemplo y breve tabla que compare las alternativas de automatización.
