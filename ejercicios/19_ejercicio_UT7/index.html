Elige un modelo NoSQL

Nivel 1 de 2 · Bases de datos no relacionales

Batería de ejercicios › UT7 › 19_ejercicio_UT7
Resultado de aprendizaje: RA7. Gestiona la información almacenada en bases de datos no relacionales, evaluando y utilizando las posibilidades que proporciona el sistema gestor.
Criterios trabajados: a), b), c), d)

Situación

Una aplicación debe almacenar un catálogo cambiante, relaciones entre amistades y eventos de telemetría de alto volumen. No todas las necesidades tienen la misma estructura ni consultas.

Enunciado

  1. Caracteriza una base de datos no relacional y compara modelos documental, clave-valor, orientado a grafos y columnar.
  2. Asigna un modelo a cada necesidad y justifica la decisión por estructura, consultas, escalabilidad y consistencia.
  3. Identifica en MongoDB los conceptos de base de datos, colección, documento, campo e identificador.
  4. Diseña un documento de producto con atributos opcionales y variantes; decide qué información conviene embeber y cuál referenciar.

Entrega

Matriz comparativa, propuesta de modelos para los tres casos y dos documentos JSON de ejemplo con campos inventados.

Material y herramientas

Descargar guion de datos ficticios para MongoDB. Ejecútalo solo en una base de pruebas.

Auto-revisión: comprueba que la entrega resuelve todos los apartados, que puedes repetir las operaciones en un entorno limpio y que explicas las decisiones de diseño. Volver al índice.
