# 20_ejercicio_UT7 · Gestiona un catálogo documental

**UT7 · RA7 · Nivel 2**
Bases de datos no relacionales

**Resultado de aprendizaje:** Gestiona la información almacenada en bases de datos no relacionales, evaluando y utilizando las posibilidades que proporciona el sistema gestor.
**Criterios trabajados:** b), c), d), e)

## Situación

Crea una pequeña base MongoDB para el catálogo TiendaTech. Puedes usar el guion ficticio incluido en Material o generar documentos propios.

## Enunciado

1. Crea la base de datos y colecciones necesarias; inserta documentos con campos anidados y arrays, y comprueba su estructura.
2. Realiza consultas con filtros, proyección, ordenación y límites; actualiza un documento y elimina solo un registro de prueba.
3. Construye una agregación que calcule unidades vendidas por producto a partir de pedidos con líneas embebidas.
4. Crea un índice adecuado para una consulta frecuente y compara el plan con explain().
5. Exporta o importa la colección con una herramienta disponible (mongosh o MongoDB Database Tools), y documenta el comando y el resultado.

## Entrega

Script mongosh reproducible, consultas CRUD, pipeline, índice y evidencia de importación/exportación. No incluyas datos personales reales.
