# Batería de ejercicios de Bases de Datos

La colección contiene 20 ejercicios en carpetas individuales (`NN_ejercicio_UTN`), ordenados por UT y dificultad. Las siete unidades trabajan su RA asociado y cubren todos sus criterios de evaluación. Los ejercicios son públicos; no se incluyen soluciones.

El origen editable está en `ejercicios.json`. Para regenerar el índice, las páginas web y los README de cada ejercicio:

```sh
python3 ejercicios/build.py
```

Los materiales de TiendaTech son inventados. Ejecuta los guiones únicamente en bases de datos de pruebas.
