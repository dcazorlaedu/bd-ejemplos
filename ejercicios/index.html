Cómo usar la batería. Los ejercicios están ordenados por unidad y, dentro de cada UT, por dificultad creciente. Las consignas no incluyen soluciones. Usa datos inventados; no publiques contraseñas ni datos personales reales. Las prácticas SQL están pensadas para una base de pruebas MySQL 8.4 y UT7 para MongoDB.
Progreso: del ejercicio 01 al 20, sin saltos.
