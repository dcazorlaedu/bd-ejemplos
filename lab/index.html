Laboratorio SQL en el navegador

Escribe y ejecuta consultas sobre TiendaTech sin instalar nada.

Este laboratorio ejecuta SQLite en tu navegador (sql.js, WebAssembly) sobre la base de datos TiendaTech. Casi todo el SQL de las unidades (consultas, DDL básico, DML, transacciones, vistas, índices, disparadores) funciona igual; lo propio de MySQL (AUTO_INCREMENT, ENUM, procedimientos y funciones almacenadas, DELIMITER, usuarios y privilegios) no existe en SQLite: para eso usa el MySQL del Docker de clase. Los cambios se pierden al recargar la página.

Tablas de TiendaTech

categorias(id_categoria PK, nombre)
proveedores(id_proveedor PK, nombre, ciudad, telefono)
productos(id_producto PK, nombre, id_categoria FK,
          id_proveedor FK, precio, stock, activo)
clientes(id_cliente PK, nombre, apellidos, email, ciudad, fecha_alta)
empleados(id_empleado PK, nombre, puesto, salario,
          id_jefe FK, fecha_contratacion)
pedidos(id_pedido PK, id_cliente FK, id_empleado FK,
        fecha, estado)
lineas_pedido(id_pedido PK/FK, num_linea PK,
              id_producto FK, cantidad, precio_unitario)
